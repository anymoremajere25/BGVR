### CHAPTER 5: Sequence Alignment and Genome Assembly

#### 5.3 Alignment and Mapping Algorithms  
This section focuses on algorithms used to align sequencing reads to reference genomes, which is a fundamental step in many genomic analyses. It introduces pairwise alignment techniques like Needleman-Wunsch and Smith-Waterman for accurate comparisons, as well as faster heuristic methods such as BLAST for large-scale data. Modern tools like BWA and Bowtie are discussed for efficient read mapping using techniques like the Burrows-Wheeler Transform and FM-index, enabling scalable analysis of high-throughput sequencing data. #### 5.4 De Novo Assembly Approaches  
Here, we explore methods for assembling genomes without a reference, known as *de novo* assembly. The section covers graph-based strategies, particularly de Bruijn graphs, which break reads into k-mers and connect them to reconstruct the genome. Challenges such as repetitive regions and sequencing errors are addressed, and commonly used assembly tools like SPAdes and Velvet are introduced. These approaches are critical for studying new or highly variable genomes.
